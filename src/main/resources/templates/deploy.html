What the registry expects

  • The repository is public.
  • Each agent lives in its own directory with an AGENT.md at its root. Agents may sit at the repository root, under agents/, or nested further — but an agent directory may not contain another agent directory.
  • Each agent resolves to a license: an SPDX identifier in the AGENT.md front matter, a LICENSE file next to the agent, or one at the repository root. Agents without a license are skipped rather than published, because Maven Central requires one.

Coordinates you will get

The artifactId is derived from the source so a coordinate always leads back to the code that produced it: <org>__<repo>__<agent>, lowercased. An agent at agents/reviewer in myorg/my-agents becomes myorg__my-agents__reviewer.

The version is YYYY_MM_DD-<short-commit>. Publishing again from the same commit on the same day is a no-op; publishing from a new commit produces a new version.
