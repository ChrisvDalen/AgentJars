How it works

An agent is a directory with an AGENT.md at its root: front matter that says what the agent is for and which tools it expects, followed by the instructions themselves. Point the registry at a public repository and every agent in it is packaged, versioned by date and commit, and published under the com.agentjars group.

Consumers add the coordinate to their build. At startup the agent files are extracted from the classpath into one directory, so an agent runtime reads them the same way it would read agents checked into the project.
